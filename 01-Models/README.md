# LangChain 01 — Models

## What I Learned

In this lesson, I learned the basic flow of using a chat model with LangChain.

### Concepts

- What LangChain is
- How to connect LangChain to an LLM provider
- How to use Google Gemini with LangChain
- How to store API keys securely using `.env`
- How to create a `ChatGoogleGenerativeAI` model
- How to send input to a model using `invoke()`
- How to access the model's response
- How to accept user input from the terminal

## Projects

### 1. Simple Robot

`simple-robot.py`

My first LangChain program. It sends a predefined question to Gemini and prints the model's response.

### 2. AI Study Assistant

`ai-study-assistant.py`

A simple interactive program where the user enters a question and the LangChain model generates an answer.

## Core Flow

User Input → LangChain Chat Model → Gemini → AI Response
